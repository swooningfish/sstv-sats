SSTV Satellite Passes

Several amateur satellites, including the ISS, send slow-scan TV (SSTV) pictures you can receive with an ordinary FM radio. Enter your location to see when each one passes overhead, follow them on a live map or 3D globe, get an alert before they arrive, and load their frequencies into your radio with CHIRP.

Quansheng UV-K1 / UV-K5 SSTV app keys F4HWN custom firmware

The SSTV app in F4HWN's custom firmware decodes pictures on the radio's own screen. It recognises Robot 36/72, Martin M1/M2, Scottie S1/S2/DX and PD50 to PD290, which covers every mode these satellites use.

  1. Install the app with UV Studio. It's part of the experimental Labs edition.
  2. Set the VFO to FM and tune to the satellite's frequency.
  3. Press F then 7 to launch the app. It starts listening straight away.

Upcoming passes

Alerts come before each pass and again when the satellite rises, but only while this page is open (on a phone, keep it on screen). On iPhone, add this page to your Home Screen first. When the page is closed, use Add to calendar or sstv-sats watch --ntfy (see the README).

CHIRP memory files

Import with File → Import in CHIRP, then upload to your radio. On 70 cm the Doppler shift is up to ±10 kHz, so the default file adds channels 10 kHz high (use at AOS) and 10 kHz low (use at LOS) around each frequency.

Receiving tips

  • Modes in use: Robot 36, Robot 72, Martin M1 and PD120/PD180. Decoders read the VIS code at the start of each picture and pick the mode automatically.
  • On a Quansheng UV-K5 or UV-K1, the F4HWN custom firmware's SSTV app decodes pictures on the radio itself.
  • FM, wide filter if your radio has one. Squelch open, volume steady, and feed the audio to MMSSTV or RX-SSTV (Windows), QSSTV (Linux), Black Cat SSTV (macOS) or Robot36 (Android).
  • Passes above 30° give the best pictures. A handheld Yagi beats a rubber duck by a mile.
  • These satellites send SSTV periodically, not all the time. Record the whole pass and decode it afterwards.
